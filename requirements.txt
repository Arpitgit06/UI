# need to match CUDA versions exactly -- each wheel bundles its own
# runtime -- but your driver needs to support the higher of the two.
#
# CPU-only / no NVIDIA GPU: install plain `torch` (no --index-url) and
# swap `paddlepaddle-gpu` for `paddlepaddle` in the command above.
